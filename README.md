# TornadoInTui

TornadoInTui is a small C++ program that renders an animated tornado directly inside your terminal using ANSI escape sequences.

## Requirements

- Linux
- C++ compiler (g++ or clang++)
- curl

## Install

```bash
curl -fsSL https://raw.githubusercontent.com/davidykmisha2015-prog/TornadoInTui/main/install.sh | sh
```

## Run

```bash
tornado
```
